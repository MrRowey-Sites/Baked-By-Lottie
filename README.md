# Baked by Lottie

Static Astro website for Baked by Lottie. Soft & Elegant design, based on the supplied official logo.

## Development

Run `npm install`, then `npm run dev`. Build with `npm run build`.

## Deployment

In Settings → Pages, select GitHub Actions. Private repository Pages availability depends on the organisation plan.

## Content before launch

The official logo is stored at `public/logo.jpg`. Add approved cake photography, product details and business policies. Enquiries currently go directly to Instagram; no personal data is collected by this site.
